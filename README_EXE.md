# KCTL RF Inspector — 실행 파일(.exe) 사용 안내

## 실행 방법

1. `KCTL_RF_Inspector` 폴더 전체를 원하는 위치에 복사합니다.
2. 폴더 안의 **`KCTL_RF_Inspector.exe`** 를 더블클릭합니다.
3. 검은 콘솔 창이 뜨고, 2초 뒤 기본 브라우저에 대시보드가 자동으로 열립니다.
4. 종료하려면 콘솔 창을 닫거나 `Ctrl+C` 를 누릅니다.

> `.exe` 파일만 따로 옮기면 동작하지 않습니다. 반드시 `_internal` 폴더와 함께
> **폴더 통째로** 복사·배포하세요.

## API Key 설정

두 가지 방법 중 편한 쪽을 쓰면 됩니다.

- **방법 A (권장)** — `KCTL_RF_Inspector.exe` 와 **같은 폴더**에 `.env` 파일을 만들고:
  ```
  OPENAI_API_KEY=sk-...
  ```
  실행 시 자동으로 읽어 사이드바에 채워집니다. 키를 바꿔도 재빌드가 필요 없습니다.
- **방법 B** — 앱 사이드바의 `OpenAI API Key` 칸에 직접 붙여넣습니다.

`.env` 없이 실행해도 앱은 켜지며, 사이드바의 **`샘플 오프라인 모드`** 를 체크하면
API 호출 없이 기본 샘플 3종으로 전체 기능(차트·성적서)을 확인할 수 있습니다.

## 포함된 자산

실행 파일 안에 계측 샘플과 성적서 서식이 포함되어 있어 별도 파일이 필요 없습니다.

- `img_1.png`, `img_2.png`, `img_3.png` — 스펙트럼 분석기 계측 이미지
- `report_template.docx` — 워드 성적서 서식

## 사용 순서

1. (선택) 사이드바에서 담당자·검토자·시료명·시험 규격을 수정합니다.
2. 계측 이미지를 업로드하거나 **`📂 기본 샘플 3종 일괄 불러오기`** 를 누릅니다.
3. AI Vision 이 `Mkr1` 마커를 판독해 KPI 카드 · Plotly 규격 차트 · 판정표를 표시합니다.
4. 보정계수(CF)·기준치(Limit) 슬라이더를 움직이면 즉시 재계산됩니다.
   (이미지별 AI 판독 결과는 캐시되어 API 가 재호출되지 않습니다.)
5. 하단 **`📥 공식 시험성적서(.docx) 다운로드`** 로 워드 성적서를 내려받습니다.

## 문제 해결

| 증상 | 조치 |
|---|---|
| 브라우저가 자동으로 안 열림 | 콘솔 창에 표시된 `http://localhost:85xx` 주소를 직접 입력 |
| 포트 충돌 | 8501 부터 사용 가능한 포트를 자동 탐색하므로 별도 조치 불필요 |
| `API Key 를 입력하세요` 경고 | `.env` 를 exe 옆에 두거나 사이드바에 키 입력 |
| 백신이 실행을 차단 | PyInstaller 빌드 특성상 간혹 오탐이 발생합니다. 예외 등록 후 재실행 |
| 첫 실행이 느림 | 번들 해제 때문에 최초 기동은 10~20초 걸릴 수 있습니다 |

## 재빌드 방법

소스를 수정한 뒤 다시 빌드하려면:

```powershell
.\ekctl_env1\Scripts\Activate.ps1
pyinstaller KCTL_RF_Inspector.spec --noconfirm --clean
```

산출물: `dist\KCTL_RF_Inspector\`
